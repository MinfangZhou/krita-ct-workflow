# CT Workflow — Krita 插件

[English](README.md) | [中文](README.zh-CN.md)

一个轻量级的 Krita 画布缩略图预览面板，支持**可读性**、**明度**和**色彩**三个观察阶段的实时效果。

为速度和稳定性而构建 —— 可流畅处理 4K 以上文档。

---

## 为什么需要它

CT Workflow 是为画师和概念艺术家设计的视觉自检工具。

它不评判构图好坏，而是帮助艺术家快速检查：

- **可读性** —— 体块分组、剪影分离、视觉平衡、视觉流向
- **明度** —— 明度可读性、眯眼模拟、景深层次
- **色彩** —— 色彩和谐、眯眼模糊观察、调色板混合

通过翻转、去色、反相、二值化和眯眼模糊等简单变换实现。

目标不是评判。

目标是看见。

---

## 功能

### 三个观察阶段（手风琴式）

每次仅展开一个阶段。缩放预览时不会推动其他阶段标题位移。

| 阶段 | 用途 | 效果 |
|---|---|---|
| **可读性** | 构图可读性检查 | 水平翻转、垂直翻转、去色、反相、二值化 + 阈值 |
| **明度** | 明度组织与眯眼观察 | 自动去色，景深滑杆（0–8）控制眯眼模糊 |
| **色彩** | 色彩和谐与混合 | 原图 / 眯眼模糊，**调色板**手绘 |

### 调色板（色彩阶段）

- **手绘** —— 在固定高度画布（120px）上绘制笔触，宽度随面板扩展
- **Krita 色彩同步** —— 自动读取 Krita 前景色用于绘画
- **Shift+点击拾色** —— 从调色板拾取任意颜色并同步回 Krita 前景色
- **笔刷大小按钮** —— 4 个固定尺寸（80 / 60 / 40 / 20 px），互斥选择
- **色彩指示器** —— 实时同步 Krita 前景色（轮询，自动更新）
- **冻结 / 对比** —— 将调色板画布与预览一起快照，用于对比
- **清除** —— 一键重置

### 共享控制

- **捕获** —— 快照当前画布用于 CT 检查
- **冻结** —— 锁定当前预览 + 调色板状态
- **对比** —— 短暂对比冻结快照与实时视图
- **鼠标滚轮** —— 缩放预览 **20%–500%**（观察距离，不是导航放大）
- **拖拽缩放** —— 在预览上按住并水平拖拽以放大/缩小。光标变为放大镜（拖拽时显示 + / −）
- **适配** —— 重置缩放以适配面板
- **调整大小抓手** —— 右侧和底部边缘的 8px 自定义抓手

### 数位笔 / 板绘拖拽缩放

| 输入设备 | 触发方式 |
|---|---|
| 鼠标 / 触摸 | **按下**预览 → **水平拖拽** |
| 数位笔（Windows Ink） | **笔尖按下**预览 → **水平拖拽** |
| 数位笔（Wintab / Wacom） | **按住空格键** → **在预览上水平拖拽笔尖** |

Windows 上的 Wintab 驱动会绕过操作系统鼠标层，因此笔尖单独无法在 Krita 插件内被检测。**空格键**回退方案使用键盘子系统，Krita 不会拦截它。

> **提示**：拖拽时保持按住空格键；达到所需缩放后松开。

## 快速安装

> **开发者注意**：Krita 从 `%APPDATA%\krita\pykrita\`（Windows）加载，而不是从你的 git 克隆目录。编辑文件后，复制到 Krita 路径并重启 Krita。

### Windows（一行命令）

```powershell
$dest = "$env:APPDATA\krita\pykrita"; New-Item -ItemType Directory -Force -Path $dest | Out-Null; Copy-Item -Recurse -Force "ct_navigator.desktop","ct_navigator" $dest
```

### 手动（全平台）

将 `ct_navigator.desktop` 和 `ct_navigator/` 文件夹复制到 Krita 的 **pykrita** 目录：

| 操作系统 | 路径 |
|---|---|
| **Windows** | `%APPDATA%\krita\pykrita\` |
| **Linux** | `~/.local/share/krita/pykrita/` |
| **macOS** | `~/Library/Application Support/Krita/pykrita/` |

预期结果：

```
pykrita/
  ct_navigator.desktop
  ct_navigator/
    __init__.py
    docker.py
    effects.py
    palette_board.py
    utils.py
```

### 启用

1. **重启 Krita**
2. **设置 > 配置 Krita > Python 插件管理器** → 勾选 **CT Workflow**
3. **再次重启 Krita**
4. **设置 > 面板 > CT Workflow** 以显示面板

## 使用

### 可读性阶段

| 控制 | 动作 |
|---------|--------|
| **捕获** | 快照当前画布 |
| **水平翻转** | 水平镜像预览 |
| **垂直翻转** | 垂直镜像预览 |
| **去色** | 灰度（亮度模式） |
| **反相** | 负片 / 反色 |
| **二值化** | 黑白，带阈值滑杆 |
| **冻结** | 锁定当前预览状态 |
| **对比** | 快速对比冻结与实时视图 |

### 明度阶段

| 控制 | 动作 |
|---------|--------|
| **景深** | 0 = 清晰去色，8 = 深度眯眼模糊 |

### 色彩阶段

| 控制 | 动作 |
|---------|--------|
| **模式** | 原图 / 眯眼模糊 |
| **调色板点击** | 用当前 Krita 前景色绘画 |
| **调色板 Shift+点击** | 拾取调色板颜色 → 同步到 Krita 前景色（🖉 图标提示） |
| **笔刷按钮** | 80 / 60 / 40 / 20 px（互斥选择） |
| **色彩指示器** | 实时 Krita 前景色预览 |
| **清除** | 重置调色板画布 |
| **冻结 / 对比** | 快照并对比调色板 + 预览 |

## CT Workflow 流程

```
绘画
  ↓
捕获
  ↓
可读性 CT 检查（翻转 / 反相 / 二值化）
  ↓
明度 CT 检查（去色 + 眯眼景深）
  ↓
色彩 CT 检查（眯眼模糊 / 调色板混合）
  ↓
冻结
  ↓
继续绘画
  ↓
对比（快速对比）
  ↓
判断可读性 / 明度 / 色彩上的漂移
```

## CT Workflow 不是什么

CT Workflow **不是**实时导航器。

它是一个**基于快照的可读性检查工具**。

预览仅在用户明确点击**捕获**时更新。

这保证了：

- 检查稳定性
- 可读性冻结
- 快速对比一致性
- 低开销性能

## 性能说明

- **大文档**：4K 画布在任何效果运行前先预缩放到 ≤1024 px，因此切换效果保持即时响应。
- **渲染管线**：先缩放 → 在小缩略图上应用效果 → 显示。无全分辨率像素循环。
- **反相**：使用 `QImage.invertPixels()`（C++ 原生），零 Python 开销。
- **去色 / 二值化**：使用 `bytearray` 批量操作，替代慢速的 `pixel()` / `setPixel()`。
- **调整大小**：100ms 防抖；拖拽面板边缘不会触发重绘风暴。
- **调色板画布**：固定 120px 高度，动态宽度；调整大小时通过左上角对齐保留内容（无拉伸）。
- **拖拽缩放**：以 50 fps 轮询，5px 死区和 3% 缩放阈值抑制帧间抖动。

## 文件结构

```
ct_navigator/
  ct_navigator.desktop       # 插件元数据
  ct_navigator/
    __init__.py              # 入口点（注册 Docker）
    docker.py                # 面板 UI、阶段、捕获、缩放、调整大小、冻结/对比
```

## 已知限制

- **Wintab 数位笔点击工具栏按钮**（捕获 / 冻结 / 对比）可能偶尔失效，因为 Wintab 事件在 Krita 内部并不总是转换为 Qt 鼠标事件。鼠标点击保持完全响应。

## 兼容性

- **Krita 5.2+**
- **Python 3.10+**（随 Krita 捆绑）
- **PyQt5**（随 Krita 捆绑）
- 无外部依赖
